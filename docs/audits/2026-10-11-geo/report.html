Vecsy GEO 优化记录

执行摘要

2026-10-11：补齐四语言静态产品指南、操作步骤、六组问答、编辑器入口与站点地图。目标是提供可检索、可抽取、可核验的官方答案素材；没有平台采样，无法证明 AI 推荐率或引用率提升。

输入与范围

对象为 Vecsy 浏览器 SVG 编辑器。目标问题：免费 SVG 编辑、修改颜色与文字、SVG 导出 PNG/WebP、文档是否上传、位图转矢量边界。来源为当前项目源码。线上首页读取失败，不将本地状态等同线上部署状态。

页面组合

原站只有编辑器首页，无独立一级或二级内容页面。本次新增一级指南路径，每种语言独立地址；以指南内 steps 和 faq 锚点替代二级页面抽样，避免为层级数量制造薄内容。

公开答案素材

指南直接说明产品是什么、费用与账号要求；操作步骤回答如何导入、选择图层、修改属性及导出；问答回答本地存储、外部资源过滤、格式区别、位图非自动描摹及复杂 SVG 显示差异。

证据台账

观察，高可信度：原首页存在 canonical、WebApplication、robots、sitemap，但静态介绍位于 React 根容器，启动后被编辑器替换。来源：index.html。

观察，高可信度：编辑器具有属性编辑、对齐、导出入口；本地文档保存使用 IndexedDB。来源：src/main.jsx 与 src/storage/document-db.js。

标准，高可信度：Google 结构化数据规则要求标记与用户可见内容相符。来源：Google Search Central 的 General structured data guidelines。

缺口：未取得服务器日志、Search Console、AI 平台采样和现场性能数据。

抓取与渲染

指南为真实静态 HTML，不依赖客户端 JavaScript。各语言 canonical 指向自身，hreflang 互相连接，x-default 指向英文指南。首页继续使用原 canonical；不为同一个编辑器 URL 伪造多语言地址。robots 保留原训练爬虫限制。

移动与性能

指南使用 viewport、流式宽度、自动折行、系统字体，无外部脚本或字体请求。移动与桌面共用完整内容。尚未测量线上 LCP、INP、CLS，发布后再用实际环境复测。

结构规范

每份指南包含 main、一个 H1、步骤与问答 H2、问题 H3、有序步骤列表、语言导航与产品源码链接。编辑器增加指南入口，静态首页增加四语言指南链接，并用 main 标识初始 HTML 主内容。

内容证据

去掉“任意 SVG”兼容性的过强描述。说明字体、外部资源、安全过滤可能改变显示；导出备份以防清除浏览器存储导致丢失。没有补造客户、评测、效果数字或资质。

AI 可抽取性

每个问答均可独立理解，关键概念包括 SVG、矢量路径、PNG、WebP、浏览器本地保存。中文指南提供中文官方答案素材，无法据此推断特定国内平台是否收录。

Schema 一致性

指南使用 WebPage，about 指向首页 WebApplication 实体。name 与 description 来自可见标题和摘要。未添加评价、评分或 FAQ 富结果承诺。文案集中在 COPY 四语言对象中，生成脚本同步正文与 schema。首页切换语言时，同步 WebApplication 描述，并保留实体 ID、功能列表和支持语言。

来源责任

指南提供项目实际 GitHub 源码入口。不添加未经核实的 sameAs、作者资质或组织关联。产品主体使用 Vecsy，保留现有实体 ID。

修复与验收

P1：缺少稳定可读的官方说明。负责人：项目维护者；成本：小。动作：增加四语言静态指南。验收：构建产物包含四份 HTML，禁用脚本后仍有正文。

P1：内容发现入口不足。负责人：项目维护者；成本：小。动作：编辑器和静态首页添加指南链接，构建自动生成 sitemap。验收：链接和地图指向实际文件。

P2：兼容性描述过强。负责人：项目维护者；成本：小。动作：去掉任意文件描述并补功能限制。验收：可见文案与源码功能一致。

代码示例：页面的 canonical 指向自身地址；结构化数据的 name 等于指南 H1；新增生成命令 npm run generate:guides，prebuild 自动运行。

内容维护

开发启动、构建、浏览器及 WebKit 测试前自动生成指南，避免旧文件影响开发与验证。新增或更新指南时编辑 src/app/copy.js 的 guide 文案组，再运行生成命令。禁止只修改生成后的 HTML，以免下次构建覆盖。当前不添加 llms.txt：先保障真实公开正文与链接，而非把辅助文件当作效果保证。

追加修复与回归验证

语言切换回归测试先确认 JSON-LD 描述仍为英文，再修复元信息更新函数。新增四语言指南测试，验证实际 HTTP 响应、正文、步骤、FAQ、互相连接的语言链接、canonical、schema 和 sitemap。外部图片说明已按安全输入代码更正：导入时会移除远程图片链接，保留合规的嵌入位图数据。浏览器测试同时验证该行为。

路线图

本次先落地代码与指南。发布后检查指南 HTTP 200、线上 canonical、实际 sitemap 和移动布局；按相同问题进行多轮平台采样，记录时间、答案和引用 URL。只有拿到样本后再分析效果。

完整性自检

范围、证据、抓取、结构、内容、抽取、schema 和边界已记录。构建与单元测试结果在最终交付中列出；浏览器集成测试独立执行。报告四格式同源。未验证项包括线上部署、真实收录、抓取频次、平台引用效果和现场性能。
