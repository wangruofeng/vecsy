# Vecsy SEO 审计与修复

日期：2026-10-01。范围：线上 https://vecsy.top/、项目源码、修复后的本地渲染。目标：免费在线 SVG 编辑器相关搜索。未接入 Search Console 或流量分析，不能判断真实收录、排名或自然流量。

## 整体结论

基础抓取配置正常；发现并修复标题被运行时缩短、语言元信息不一致、分享预览爬虫被阻止、字体请求被 CSP 阻止，以及导出功能描述遗漏。修改在本地，尚未部署，线上仍是原版本。

## 页面与内容

首页存在一个产品 H1，无重复产品主标题。修复英文描述，说明本地处理与 SVG/PNG/WebP 导出；同步四语言描述和图片替代说明。静态兜底内容与 JSON-LD 补齐已实现的导出与对齐功能。桌面和 390px 手机视口检查均无页面横向溢出。

编辑器功能面板是主要可见内容，静态介绍在 React 挂载后被替换；这限制了功能说明的搜索内容深度。后续适合增加真正可见的使用指南、导出说明和隐私说明，而非隐藏关键词或生成薄内容页面。尚未评估竞品、外链、作者信誉或流量表现，不作推断。

## 国际化与后续优先级

1. P1：如需中文和日文分别获得搜索入口，增加独立语言 URL、完整可见内容、自引用 canonical、双向 hreflang、语言链接及 sitemap；当前仅一个 URL，不伪造语言页面或 hreflang。Google 建议为不同语言使用不同 URL：[官方多语言指南](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites)。本次同步客户端元信息不等于四语言已独立收录。
2. P2：增加可见产品使用说明和明确的隐私说明，逐页按用户任务组织内容。
3. P2：部署后在 Search Console 验证首页、提交 sitemap 并检查真实索引结果；没有该账号数据，不能自动执行或确认。
4. P2：获取 PageSpeed / CrUX 或实际用户性能数据后再优化 LCP、INP、CLS。本次没有性能评分或真实用户数据，手机布局检查不等于 Core Web Vitals 达标。
